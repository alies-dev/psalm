Psalm crashes with "Could not get class storage for stdclass" when a template's bound names a class that nothing else in the code base mentions, and the template is read through that bound.

**Before**
```php
<?php
/** @template TArr of array{a: DateTime, b: stdClass} */
abstract class Holder {
    /** @return value-of<TArr> */
    abstract public function read(): mixed;
}

/** @return Holder */
function holder(): Holder {
    throw new Exception();
}

$value = holder()->read(); // crash: Could not get class storage for stdclass
```

**After**
```php
$value = holder()->read(); // DateTime|stdClass
```

Fixes #13502
