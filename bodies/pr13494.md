### Param-conditional return on a `$this`/`static` callable

When a conditional return type depends on whether a callback param is `null` and the callback's param type uses `$this` or `static`, a non-null callback still gets both branches (`Box|int` instead of `Box`).

**Before**
```php
<?php
final class Box {
    /**
     * @param (callable($this): mixed)|null $callback
     * @return ($callback is null ? int : $this)
     */
    public function tapThis(?callable $callback = null) {
        throw new RuntimeException();
    }
}

$box = new Box();
$this_ = $box->tapThis(fn (Box $_b): int => 1); // Box|int
```

**After**
```php
$this_ = $box->tapThis(fn (Box $_b): int => 1); // Box
```

### Untyped closure param of a `callable(static)` param

The param of an untyped closure passed to a `callable($this)` or `callable(static)` param gets the calling class (or a bare `static`) instead of the class the method is called on.

**Before**
```php
<?php
class Base {
    /** @param callable(static): mixed $callback */
    public function each(callable $callback): void {}
}

final class Items extends Base {}

final class Consumer {
    public function run(Items $items): void {
        $items->each(function ($item): void { // InvalidArgument: Argument 1 of Items::each expects callable[impure](Items):mixed, but Closure[pure](static):void provided
            /** @psalm-check-type-exact $item = Items */ // CheckType: Checked variable $item = Items does not match $item = Consumer&static
        });
    }
}
```

**After**
```php
        $items->each(function ($item): void { // no issue
            /** @psalm-check-type-exact $item = Items */ // no issue
```

Unchanged from master: forwarding calls (`parent::`, `self::`, `static::`, a non-static method called as `Base::method()` from a subclass), template and intersection receivers keep master's closure hint and decision; an untyped closure on a generic receiver (`Coll<int>`) still gets a false positive, now `ArgumentTypeCoercion`/`MixedArgumentTypeCoercion` instead of `InvalidArgument`, because arguments are still checked against the class name.
